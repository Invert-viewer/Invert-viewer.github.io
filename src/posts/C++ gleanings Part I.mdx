### 程序设计概念

<Collapse title="基本概念(程序、计算机语言、编辑和编译、IDE)">

* 程序:用计算机编写的一系列指令序列
* 计算机语言:人与计算机之间通信的语言，有许多不同的语言，而且即使是同一种语言也有不同的版本。~~点名批评python2和python3~~！
* 编辑:在某种计算机语言环境下编写程序的过程
* 解释:翻译一句执行一句。例如Java
* 编译:一次性全部翻译，在执行。例如C++
* IDE::ruby[集成开发环境(Integrated development environment)],一般集成了编辑、编译和调试功能。**所有IDE都是天下第一IDE**

</Collapse>

#### 程序结构

下面要请出经典的“hello,world”啦！>ω&lt;

```cpp
# include<iostream>               //头文件
using namespace std;              //名字空间，std指的是标准名字空间
int main(){                       //主函数
    cout<<"hello,world"<<endl;  //主函数
    return 0;                     //主函数(一般每个函数都有返回值，所以有了这句)
}
```

C++程序由头文件、名字空间和主函数构成。

<Collapse title="1.头文件" type="info">

引用其他程序，用于保存程序的声明。格式如下：

```cpp
#include<>  //尖括号和引号里面加上引用文件名
#include""
```

</Collapse>

<Collapse title="2.名字空间" type="info">

防止编写大型程序时名字产生冲突。*（或者说方便指明函数是哪来的）*
</Collapse>

<Collapse title="3.主函数" type="info">

一般的“函数”，都是实现某种功能的。在大多数程序里面，main函数是必须存在的，它是优先运行的。

</Collapse>

### 整数算数运算

#### cout语句

* 作用:输出，通过:ruby[流(stream)]的方式来实现的。
* 输出一般遇到endl或“/n”会换行。
* 格式如下：

```cpp
cout<<项目1<<项目2<<...<<项目n;
```

* 如果项目是表达式，则输出值。
* 如果项目加引号，直接输出。

#### 算数运算(符)

:ruby[加(+)]、:ruby[减(-)]、:ruby[乘(*)]、:ruby[除(/)]和:ruby[模(%)]

* 除法结果是整数，没有小数部分
* 模是取两数相除的余数，也是整数。
* 运算顺序同一般数学计算

#### 实数运算

5和5.0是不一样的，在数学上面意义相同，可是前者是实数，后者是整数。二者不同会影响除法和取模运算的结果。

## 第二章 数据的存储和读入

### 数据类型

这里仅列举一部分常用的：
1.整数类型int,占用4字节，表示-2^31到2^31范围内的**整数**。
2.双精度浮点类型double，表示最大整数1.8×10^308范围内的浮点数(也就是小数)。
3.字符型char，占用1字节，表示-128到127范围内对应的字符

:::primary

科学计数法:例如3.40E+38表示3.40×10^38。

:::

:::primary

查看数据类型占的字节数目可以用sizeof()函数。
:::

:::warning

如果数据类型选的不对，还强行把数据放进去，就会造成:ruby[数据溢出(overflow)]错误,而且***编译器看不出来***！！！

:::
